# Nav Bar Bro

A minimal navigation-bar demo — one cyan nav bar with a profile photo and four buttons, and nothing else on the page.

## What it is

This repo contains just a navigation bar. The whole page is a single `<nav class="nav">` element holding a circular profile photo (`1.PNG`, linking to the author's GitHub profile) and four transparent buttons labelled Education, Study, Project, and Contect (class `.ode`). The page body below the bar is empty — the bar itself is the demo. One quirk to know: in `index.html` the `<nav>` element sits inside the `<head>` rather than the body, though browsers still render it.

## Files

- `index.html` — the page (titled "My Resume") containing only the nav bar markup.
- `style.css` — the cyan bar (`rgb(0, 255, 255)`), right-aligned buttons with wide letter spacing, and hover effects that bold and expand the buttons.
- `1.PNG` — the profile photo shown in the bar.
- `Link` — text file recording the GitHub Pages URL this page was deployed to.
- `README.md` — this file.

## Run it

Open `index.html` in a browser.
